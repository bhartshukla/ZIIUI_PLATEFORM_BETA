What is ZiiUI?

ZiiUI is a curated component platform designed to bring high-end motion, micro-interactions, and visual polish to web creators and developers without the overhead of starting every complex animation from scratch.

Instead of wrestling with mathematical easing functions, shader uniforms, or scroll-pinning calculations, you can browse pre-built components, inspect their live behavior, make AI-assisted adjustments, and copy clean, production-ready code into any tech stack.

Zero configuration needed. You can explore and preview every component without writing a line of code. All copied components include standalone CDN dependencies so you can run them immediately in any browser.

Quick Start

Get any animated component running in your project in less than two minutes:

  1. Select a Component: Open the Components Library and pick any component card.
  2. Inspect Live Preview: Interact with the preview canvas to verify animation speed, hover states, and gestures.
  3. Switch to Code: Click the Code tab to inspect the clean markup, CSS styling, and JavaScript logic.
  4. Copy Full Component: Click Copy Full Component to copy the self-contained bundle with required CDNs.
  5. Paste & Run: Paste into an index.html file in your project and serve via any local dev server or static host.
HTML · Standalone Example 
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <title>ZiiUI Animated Component</title>
  <!-- GSAP CDN dependency -->
  <script src="https://cdnjs.cloudflare.com/ajax/libs/gsap/3.12.5/gsap.min.js"></script>
</head>
<body>
  <!-- Paste component markup and styles here -->
</body>
</html>
Do I need npm or a build step? No npm packages are required for copied components. All external animation engines (GSAP, Three.js, Lenis) are loaded via standard lightweight CDNs.

Live Preview & Testing

Before copying code, test components interactively inside the built-in preview sandbox:

  • Hover & Magnetic Tracking: Move your pointer over cards, thumbnails, or buttons to observe physics and cursor velocity.
  • Scroll Simulation: Scroll vertically within the preview container to verify ScrollTrigger pinning and scrubbed animations.
  • Pointer & Drag: Click and drag draggable mask windows or interactive nodes to inspect gesture response.
  • Responsive Scaling: Resize your browser viewport to verify that fluid typography and flexbox/grid containers adapt cleanly.

Adding to Your Website

Integrating a ZiiUI component into your site takes only a few lines:

Method A

Vanilla HTML & Static Sites

Paste the copied HTML directly into your template. Ensure the external library CDNs are placed in the <head> or before the closing </body> tag.

Method B

React, Next.js, Vue, Svelte

Mount the HTML structure inside your component JSX/template, import GSAP via npm (import gsap from 'gsap'), and run the animation logic inside useEffect or onMounted.

Customizing Without AI

You have full control over the copied code. All components are written in standard, clean CSS and JavaScript:

  • Content & Assets: Replace demo text headings, paragraphs, and image URLs (src="...") directly in the HTML.
  • CSS Variables: Tweak color variables such as --accent, --bg, and --card-bg in the CSS root.
  • Animation Timing: Modify GSAP tween parameters (e.g. duration: 1.2, stagger: 0.05, ease: "power3.out").
  • Scroll Scrubber: Adjust scrub: 1 in ScrollTrigger configurations for tighter or looser scroll momentum.

Frequently Asked Questions

Q1

Is ZiiUI free for commercial use?

Yes. Components and code exported from ZiiUI can be used freely in personal, client, and commercial projects.

Q2

Do I need to install ZiiUI via npm?

No. Copied component code is standalone HTML, CSS, and JS with external CDNs included. No npm package installation is needed.

Q3

Does AI overwrite my components?

No. AI generates a draft copy in browser session memory. The underlying library component is never altered, and you can reset anytime.

Q4

Can I adapt components to React or Vue?

Yes. The HTML, CSS, and JavaScript can be placed directly inside React functional components or Vue single-file components.

Troubleshooting

Issue

Animation is not triggering

Check browser console for CDN loading errors. For scroll effects, ensure the page has sufficient scroll height and call ScrollTrigger.refresh() if content loads dynamically.

Issue

Images or icons not rendering

Verify that the Remix Icon stylesheet link is included in your document <head> and check image URL network status in dev tools.

Developer Reference

Architecture overview for contributors and power users:

  • Component Registry: Located at src/effects/registry.js with template builders at src/effects/builders.js.
  • AI Engine & Storage: Client request management in src/ai/client.js and resilient session storage deduplication in src/ai/state.js.
  • Performance: All transforms utilize hardware-accelerated 3D transforms (translate3d, will-change) with RAF-throttled scroll listeners.
  • Accessibility: Semantic landmarks, ARIA attributes (aria-expanded, aria-label, role="log"), and keyboard navigation support.
