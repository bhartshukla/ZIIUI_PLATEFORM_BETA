What is ZiiUI?

ZiiUI is an animated UI component library that helps you create modern, interactive websites without building every animation and interface element from scratch.

Instead of starting from zero, you can explore existing components, preview how they look and behave, copy their code, or customize them using AI. ZiiUI gives you two ways to work:

01

Edit with AI

Personalize a component according to your ideas. Describe what you want to change and AI generates an edited version.

02

Ready-to-use Components

Select an existing animated component, preview it, copy its code, and add it to your website.

No coding experience required to explore. You can browse and preview every component without writing code. Basic HTML knowledge helps when you paste the code into your own site.

Feature 01

Your Idea. Your Design. Customized with AI.

Have a design in mind? Describe what you want to change in normal language, and ZiiUI's AI editing workflow personalizes a selected component for you.

Step 5

Review Your Design

Step 6

Refine Your Design

Ask AI for further changes or manually edit the code yourself.

Step 7

Copy or Export

Copy the edited code or export it as a standalone HTML file.

What Can I Ask AI to Change?

Where supported by the component, you can request changes to:

  • Background colors
  • Text colors
  • Font size and typography
  • Layout and alignment
  • Spacing
  • Borders and buttons
  • Hover effects
  • Animation speed and timing
  • Responsive appearance

Be specific. Mention the element, its appearance, and the exact change you want. The more detail you give, the better the result.

Original Design Protection

AI editing creates an edited draft. It does not overwrite the original component in the source library. Use Reset to Original when you want to discard your changes and start over.

AI configuration. AI editing requires the AI service to be configured. If AI is not configured, the component library and ready-to-use features remain fully usable — AI generation simply won't work.

What Are Dependencies?

Some components need additional libraries to create their animations or visual effects. A dependency is simply an external tool that helps a component work.

Examples of dependencies you may see include:

  • GSAP — for animations.
  • ScrollTrigger — for scroll-based effects.
  • Lenis — for smooth scrolling.
  • Three.js — for shader visuals.
  • Google Fonts — for typography.

Check the selected component's dependency list and keep the included CDN references when you copy the full component. You don't need to install every library for every component — only the ones that component lists.

Do I need npm? No. For the copied standalone component code, a separate npm installation is not required when the provided CDN setup is retained. ZiiUI itself does not currently provide a package-based npm installation method. Running the ZiiUI application locally is different from using copied component code on your site.

Which Way Should I Use ZiiUI?

You have two main paths. Choose the one that fits your situation.

AI

Use Edit with AI when:

  • You have a specific design in mind.
  • You want to change the appearance.
  • You want to personalize an existing animation.
  • You want AI to help with code modifications.
Ready-made

Use Ready-to-use Components when:

  • You like an existing design.
  • You want to save development time.
  • You want to copy a working component.
  • You want to explore different effects.
You can combine both. Start with a ready-made component, then use AI to personalize it further.

Frequently Asked Questions

Q

What is ZiiUI?

ZiiUI is an animated UI component library with AI-assisted customization.

Q

Do I need coding knowledge?

Basic HTML/CSS/JavaScript knowledge is helpful when integrating and modifying components. You can explore and preview components without understanding their internal implementation.

Q

Can I use components without AI?

Yes. The ready-to-use component library works independently of AI configuration.

Q

Does AI work automatically?

AI editing requires the AI service to be configured. If it is not configured, AI generation will not work.

Q

Can I preview before copying?

Yes. Open the component detail view and use its live preview.

Q

Can I edit the component after copying it?

Yes. You can modify the copied HTML, CSS, and JavaScript in your own project.

Q

Do I need to install ZiiUI?

No package installation is required for copied standalone component code. Keep the dependencies included in the generated HTML.

Q

Can I use components in React or Vue?

The generated output is standalone HTML. Using it in a framework may require adapting its markup, styles, and JavaScript to that framework.

Q

Why is an animation not working?

Check the component's dependencies and ensure its required CDN resources load correctly. Some effects require scrolling, hovering, or dragging inside the preview.

Q

Can I use components on mobile?

Responsive behavior and touch support vary by component. Check its preview and individual notes before integrating it.

Q

Does AI overwrite the original component?

No. AI editing creates a draft and preserves the original component.

Troubleshooting

1

AI is not generating changes

Check whether AI is configured and available.

2

Preview is blank

Check the browser console and whether external resources are loading.

3

Animation is not starting

Try the correct interaction. Some components require scrolling, hovering, or dragging.

4

Images are missing

Check image URLs and internet access.

5

Copied component looks different

Make sure you copied the full component and retained its required styles, scripts, fonts, and dependencies.

6

Component is not working on mobile

Check its mobile behavior and touch support. Some pointer-based effects are designed primarily for desktop.
