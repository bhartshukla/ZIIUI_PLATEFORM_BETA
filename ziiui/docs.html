Introduction

What is ZiiUI?

ZiiUI is a frontend-first creative effects and animated UI component library. It provides ready-to-use animated and interactive UI components that you can preview in the browser, inspect as generated HTML, CSS, and JavaScript, and copy directly into your own projects.

  • Discover animated and interactive UI components grouped by category.
  • Preview each component's actual animation and interactions in the browser.
  • Inspect generated HTML, CSS, and JavaScript for every component.
  • Copy code for use in your projects via Copy HTML, Copy CSS, Copy JavaScript, or Copy Full Component.
  • Customize supported component settings such as text and effect options where available.
  • Use the existing AI Editor to iterate on a component's code with natural language.

ZiiUI is front-end focused: it runs in the browser with no backend or database. Generated snippets are standalone HTML documents that load any required libraries from public CDNs.

Quick Start

Quick Start

1

Choose a Component

Open the Components Library, browse by category, and select a component card to open its detail view.

2

Preview It

Inspect the live preview. For scroll effects, scroll the preview; for interactive effects, hover or drag inside it.

3

Inspect the Code

Switch to the Code view and use the HTML, CSS, and JavaScript tabs to read the generated output.

4

Copy the Code

Use Copy HTML, Copy CSS, Copy JavaScript, or Copy Full Component. Export HTML downloads a standalone file.

5

Add It to a Project

Paste the copied code into an HTML file or your framework. Load required libraries from the CDN links included at the top of the output.

Tip. Every component checks prefers-reduced-motion and skips its animation when needed. Keep that guard in place in copied code.

Installation and Setup

Installation and Setup

ZiiUI website setup

ZiiUI is a static frontend app. Run it locally with Vite:

Shell
npm install
npm run dev

Then open the local URL shown by Vite (typically http://localhost:5173).

The app must be loaded over http:// or https://. Opening HTML directly from disk via file:// is not supported for the interactive preview flow.

Using copied component code in another website

Copied component code is a standalone HTML document. It loads its own dependencies from public CDNs (GSAP, ScrollTrigger, Lenis, Three.js) where needed. No package installation is required for the copied snippet itself.

  • Text effects: no external dependencies. Plain HTML, CSS, and JavaScript.
  • Scroll effects: require GSAP, ScrollTrigger, and (for some) Lenis and SplitText, loaded from CDN.
  • Shader effects: require Three.js, loaded from CDN.
  • Interactive and menu effects: require GSAP where noted in each component's Dependencies section.
  • Some components reference external images or fonts loaded from CDNs or image hosts.

ZiiUI does not provide a package-based installation method. Do not imply installing ZiiUI as an npm package; use the copied standalone code instead.

Code Example — Text Effect

HTML
<p id="t">Animate your ideas</p>
CSS
.u { opacity:0; transition: opacity .5s ease; transition-delay: calc(var(--i)*.03s); }
.u.on { opacity:1; }
JavaScript
const el = document.getElementById('t');
const text = el.textContent;
el.textContent = '';
let i = 0;
text.split(/(\s+)/).forEach(part => {
  if (!part) return;
  if (/^\s+$/.test(part)) { el.append(part); return; }
  const w = document.createElement('span'); w.className='w';
  [...part].forEach(ch => { const s=document.createElement('span'); s.className='u'; s.style.setProperty('--i', i++); s.textContent=ch; w.append(s); });
  el.append(w);
});
requestAnimationFrame(()=>requestAnimationFrame(()=>el.querySelectorAll('.u').forEach(u=>u.classList.add('on'))));

Split Scroll

Category: Web  ·  Preview size: Large

Overview

A full-screen scroll-driven section where three cards split apart with a growing gap, then flip in sequence. Used for storytelling hero sections.

What It Does

On scroll, the stage scales down, a gap opens between three card slices, and the cards flip over to reveal their backs. Hero parallax moves the headline and copy.

Features and Effects

  • Stage scale-in entrance.
  • Gap opens between card slices (clip-path split).
  • Staggered 3D card flips.
  • Hero parallax on headline and copy.

Interactions

  • Scroll (scrubbed timeline).

Customization

No editable text field (field: 'none'). Adjust via code: gap target, phase timings, card content, fonts.

How It Works

Uses GSAP + ScrollTrigger with Lenis smooth scroll. Clip-path insets create the visual split; a proxy value animates the gap; cards flip with rotateY.

Code

HTML structure, CSS layout, and JavaScript (GSAP/ScrollTrigger/Lenis) are generated. Requires the CDN scripts listed in Dependencies.

Dependencies

  • GSAP 3.12.5
  • ScrollTrigger
  • Lenis 1.1.14
  • Google Fonts: Bebas Neue, DM Sans
  • Remixicon

Assets and Setup

No external images required beyond template defaults. Internet connection needed for CDN libraries on first load.

Responsive Behavior

Layout adapts via flex; resize handler refreshes ScrollTrigger. Large preview size.

Accessibility

Respects prefers-reduced-motion via GSAP defaults where applicable. No keyboard interaction documented.

Limitations and Notes

Heavy on GPU/layout. Use one hero-level effect per page.

Related Components

Pin Rotate Sections, Images Flow (other scroll-driven effects).

Draggable Mask

Category: Interactive  ·  Preview size: Large

Overview

Draggable canvas windows that reveal a clipped region of an underlying video.

What It Does

Canvas masks follow pointer drag over a video, drawing the clipped video region inside each mask. A HUD shows live coordinates.

Features and Effects

  • Draggable mask containers.
  • Live clipped video rendering via canvas.
  • Coordinate HUD overlay.

Interactions

  • Drag (mouse down/move/up).
  • Hover (mouseenter/mouseleave on masks).
  • Pointer move (global HUD).

Customization

No editable text field. Adjust mask count, size, and video source via code.

How It Works

Canvas 2D draws clipped video frames per mask using drawImage with computed scale/offset. State tracked in a Map.

Dependencies

  • None (vanilla JS, HTML5 video/canvas).

Assets and Setup

Requires a video source. External video URL must be reachable.

Responsive Behavior

Large preview size; video scales to viewport aspect.

Accessibility

Mouse-driven only; no keyboard interaction documented.

Limitations and Notes

Performance depends on video resolution and mask count.

Guides

Exploring Components

Browse categories in the Components Library sidebar, filter by category chips, and open a component card to view its detail page with preview and code.

Previewing Components

The detail view shows a live preview in a sandboxed iframe. Use the Open in new window and Fullscreen actions. Scroll effects require scrolling inside the preview; interactive effects respond to hover/drag.

Working with Generated Code

Switch to the Code view for HTML, CSS, and JavaScript tabs. Use Copy HTML, Copy CSS, Copy JavaScript, or Copy Full Component. Export HTML downloads a standalone file. Each output is a complete HTML document.

Customizing Components

Text components expose a text field plus split/preset controls (Text Effect). Other components have no editable controls in the UI; customize by editing the generated code. The AI Editor can iterate on a component's code with natural language where configured.

Integrating Components into a Website

Paste copied code into an HTML file or framework component. Keep CDN script/style tags. Ensure external images/fonts are reachable. Host on any static server (GitHub Pages, Netlify, Vercel).

Responsive and Accessibility Considerations

Text effects use clamp for responsive sizing. Scroll/interactive effects use large previews. Every component checks prefers-reduced-motion where implemented; verify per component. Keyboard support varies; many effects are pointer/scroll-driven. Apply additional accessibility (focus management, ARIA) in your integration as needed.

Dependencies and Libraries

  • GSAP 3.12.5 — animation engine for scroll, interactive, menu, footer effects.
  • ScrollTrigger — scroll-driven timelines.
  • Lenis 1.1.14 — smooth scroll.
  • Three.js r128 — WebGL shaders.
  • SplitText (GSAP) — text splitting for Scroll Stand.
  • Google Fonts — per-component font families.
  • Remixicon — icon set.

Troubleshooting

  • Missing external library: ensure CDN script tags are present and reachable.
  • Missing image/asset: verify image URLs and network access.
  • Component not rendering: check console for JS errors; ensure running over http/https.
  • Animation not triggering: scroll effects need scroll inside preview; check reduced-motion settings.
  • Responsive layout issue: verify viewport meta and container widths.

FAQ

What is ZiiUI?

A frontend-first creative effects and animated UI component library with preview and code export.

How do I find a component?

Browse by category in the Components Library or this docs Component Reference.

How do I preview a component?

Open its detail view; the preview runs in a sandboxed iframe.

How do I copy component code?

Use Copy HTML, Copy CSS, Copy JavaScript, or Copy Full Component in the Code view.

What is included in Copy Full Component?

The complete standalone HTML document.

Do components require external libraries?

Some do (scroll/shader effects). Text effects require none. See each component's Dependencies.

Can I customize a component?

Text Effect exposes split/preset controls; others via code editing or AI Editor.

Can I use copied code in an existing website?

Yes; paste into HTML or a framework component and keep CDN tags.

Are all components responsive?

Text effects use clamp; others use large previews. Verify per component.

Does every component support the same controls?

No. Controls vary by component.
